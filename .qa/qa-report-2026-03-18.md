## Remaining Issues

None blocking. Two minor hardening opportunities:

1. **`validate_geneblock_overhangs()`** (`R/09_wt_geneblock_design.R:1229`): Accesses `assembly_plan$oh_L` without null-guarding `assembly_plan`. Safe in pipeline context but would crash if called standalone. Low priority — defensive `if (!is.null(assembly_plan))` guard would make it robust.

2. **`upstream_cassette` enzyme site validation**: `validate_config()` checks `upstream_cassette` for ACGT characters but does NOT check for enzyme recognition sites within the cassette. A cassette containing CGTCTC (BsmBI) would pass config validation but create an unintended cut site. Low risk in practice (typical cassettes are 0-6 nt, unlikely to contain a 6-7 nt enzyme site), but a completeness gap.

## Recommendations

1. **Commit the 32 QA tests** into the test suite as permanent regression guards.
2. Add enzyme site check for `upstream_cassette` in `validate_config()` (one-liner: same pattern used for oh_L junction checks).
3. Add null guard to `validate_geneblock_overhangs()` for standalone safety.
